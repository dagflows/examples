# Step 2: Typed Node, in TypeScript

This folder is the TypeScript project of [step 2](../README.md), which explains the code and how to
deploy it. Copy the folder to the root of a repository to deploy it.

- [workflow.ts](workflow.ts): the workflow, its types and its node
- [dagflows.yaml](dagflows.yaml): names `workflow.ts` as the project's entry
- [package.json](package.json): the project, depending on the Dagflows SDK and TypeScript
